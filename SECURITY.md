# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by emailing security@warpspeedopen.org.

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 5 business days and work with you to address the issue responsibly.

## Supported Versions

This repository contains bounty task descriptions and documentation. Security issues related to bounty implementations should be reported to the respective project maintainers.

## Security Best Practices for Bounty Submissions

Do not include API keys, private credentials, tokens, or user data in pull requests or screenshots.
